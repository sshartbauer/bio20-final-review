# BIOSC-20 Final Exam Review

A free, interactive review tool for the BIOSC-020 final exam (Fall 2026, Los Medanos College). It covers both final study guides: notes for every concept, flashcards, a quiz, the mitochondrion and chloroplast diagram drills, eight interactive practice tools, and progress tracking.

Open `index.html` through GitHub Pages. Progress is saved only in your own browser. It works offline after the first visit and is built to be usable on a phone.

Content comes from the typed text of the instructor's final study guide slides, shared with the instructor's permission. Please report mistakes by opening an issue. See `CHANGELOG.md` for versions.
